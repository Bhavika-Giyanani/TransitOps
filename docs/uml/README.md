## Viewing

Open `uml-viewer.html` in a browser (needs internet for the Mermaid library).
After editing any `.md` file, rebuild the viewer:

```
node build-viewer.mjs
```

## Recent additions reflected here

- Subscription receipt: PDFKit receipt generated by the backend and emailed during verified payment setup.
- Safety score: calculated by `backend/src/services/safetyScore.ts` and refreshed on compliance changes.
- Indian registration and licence format validation: shared helpers in `shared/indianFormats.ts`.
